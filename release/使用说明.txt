快艇骰子 · 中文离线策略助手

双击“快艇骰子策略助手.exe”即可使用，无需安装 Bun、Node.js 或 Rust，无需联网。
适用于 Windows 10/11，需要 Microsoft Edge WebView2（通常已随 Windows 或 Edge 安装）。

局面分析：同样支持保留、重掷和应用右侧建议，还可用骰子下方的下拉框或五位数字修改点数，调整当前第几掷。
掷骰练习：点击骰子保留，重掷其余骰子。两种模式共用当前局面，切换时保留所有状态；点击“记分”或应用填栏建议后都进入下一回合，可撤销。
留空表示尚未使用；0 分表示已经占用该栏。程序会自动保存当前局面。
工具栏箭头可导出、导入局面；撤销保留本次打开程序后的最近 50 步。

本版采用世界游戏大全51规则：上半区达到63分奖励35分；小顺15分、大顺30分；
四条和葫芦计五颗总和，五颗相同也算葫芦；快艇50分，没有重复快艇奖励。

建议以整局平均总分为目标，不根据对手分数优化胜率。分差表示相对最优动作损失的期望分数。

策略方法及数据来源：Smooth Pudding / yacht-evaluator-api
